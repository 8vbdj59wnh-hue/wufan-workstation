## 三、实现范围

### 1. 链接档案

平台链接导入按 `platform + shop + platformGoodsId` 识别链接。平台由店铺档案承载，链接唯一索引继续使用 `shopId + platformGoodsId`，因此兼容现有数据；京东导入时可将 SPU 映射为 `platformGoodsId`。

### 2. 五类导入

- 平台链接：创建或更新 `sales_links`，并建立链接档案。
- 平台经营：写入独立周期事实，不覆盖历史周期。
- ERP 真实销售：按链接 + SKU + 周期保存发货量、销售额、成本和利润。
- ERP 产品关系：仅按精确 SKU 编码关联 `sales_link_skus → products`。
- ERP 库存：按 SKU 和业务日期保存当前库存、可售库存、成本和销售速度。

### 3. 导入治理

- 导入模板主体与模板版本分离，迭代生成新版本，历史版本不覆盖。
- 支持标准字段自动识别及自定义 Excel 字段映射。
- 每次导入保留文件哈希、类型、来源、时间、成功数和异常数。
- 每行保留原始数据、标准化数据和错误原因。
- 缺商品 ID、缺 SKU、缺字段及错误数值格式进入异常列表，不执行模糊猜测。
