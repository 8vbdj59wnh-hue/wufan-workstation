# 链接中心 V3 Phase4 经营驾驶舱验收报告

## 1. 验收结论

经营链接中心已新增“经营驾驶舱”，完成经营总览、核心链接、风险链接、增长链接、平台渠道、产品渠道和经营趋势展示。全部数据来自 V3 既有事实与关系，没有新增经营事实表、复制销售数据或修改 Phase1–3 业务模型。

结论：开发验收通过，可以提交；本次不发布。

## 2. 实现内容

- 新增只读聚合接口：`GET /api/connection-business-cockpit`。
- 新增经营链接中心“经营驾驶舱”入口。
- 经营总览：链接规模、医院阶段、ERP发货销量、销售额、同期变化、利润、利润率。
- 健康分布：健康、关注、异常、待积累数据。
- 核心链接：仅展示存在 ERP 真实销售周期的链接，按销售额、利润、销量排序。
- 风险链接：复用健康状态及销售、利润、流量、转化异常规则，并提供链接医院入口。
- 增长链接：比较销售、利润、流量和转化变化，按最大正向幅度排序。
- 平台渠道：按平台汇总链接数、ERP销售额、利润、利润率和健康率。
- 产品渠道：通过 `链接 → SKU → 产品` 汇总最新 ERP 销售贡献及平台占比。
- 经营趋势：按日/周/月展示 ERP销售、利润与平台流量，两个来源不混用。
- 核心和增长链接支持进入 V3 链接详情；风险模块支持进入链接医院。

## 3. 数据口径

- 销量、销售额、成本、利润：`connection_sku_sales_facts`。
- 流量与转化：`connection_period_snapshots`。
- 链接身份：`connection_profiles`、`sales_links`、`sales_shops`。
- 产品渠道：`sales_link_skus`、`products`。
- 健康与成长：现有连接成长分析。
- 诊断、治疗、观察：`connection_diagnosis_entries`、`connection_improvements`。

未读取模拟数据，未创建新的经营事实。
