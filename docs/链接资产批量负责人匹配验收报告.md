# 链接资产批量负责人匹配验收报告

## 一、验收结论

链接资产批量负责人匹配已完成开发并在隔离数据库验证通过。功能按“店铺 + 商品ID”精确识别链接，仅更新 `connection_profiles.ownerId`，未改动链接身份、销售事实、产品关系或经营快照。

## 二、实现范围

- 链接资产页新增“批量匹配负责人”入口，仅管理员或具备链接资产管理权限的用户可见、可调用。
- 上传 Excel 支持字段：商品ID（必填）、负责人、运营组、备注。
- 店铺由上传时明确选择，技术匹配键为 `shopId + platformGoodsId`。
- 生成确认前预览，展示总行数、已匹配、未匹配、冲突、空负责人及逐行原因。
- 确认时使用统一事务批量更新负责人；任何执行期校验失败均整体回滚。
- 链接资产负责人筛选增加“未分配负责人”和“已分配负责人”。
- 导入批次与行明细复用现有导入审计表，不新增产品、链接或经营事实模型。

## 三、匹配与异常规则

1. 仅允许使用店铺和商品ID精确匹配，不使用商品名称、SKU或货号。
2. 同一文件内商品ID重复时标记冲突并阻断整个批次确认。
3. 负责人不存在或出现同名歧义时标记冲突并阻断确认。
4. 商品ID不存在或尚无链接档案时进入未匹配清单，不猜测关联。
5. 空负责人行标记为忽略，不执行更新。
6. 相同店铺、相同文件内容再次上传返回原批次；已完成批次再次确认不重复更新。
