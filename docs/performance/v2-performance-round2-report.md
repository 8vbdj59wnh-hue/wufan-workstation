# 极简工作站第二轮流畅性优化报告

## 结论

本轮严格处理生产报告中未达标的 8 项，不修改业务规则、权限语义、状态机、销售/利润口径或 Sales Object 关系。基于生产 SQLite 在线备份的隔离副本复测后，7 个后端/数据加载项均低于 1 秒；经营链接驾驶舱不再出现 30 秒以上主线程阻塞，首屏 DOM 从 11,448 个节点降至 1,543 个节点。

当前 Mac 服务器不是本轮剩余瓶颈，可以结束本轮流畅性专项。代码暂未发布生产。

## 任务、产品和模板查询证据

- 任务接口按 `scope → count → query → hydrate → context → serialize` 输出分阶段耗时。生产副本当前页典型值：count 约 2ms、分页 SQL 约 1.5ms、当前页上下文约 6ms、序列化约 3.5ms。
- 新增 11 个证据明确的组合/外键索引，覆盖任务状态与截止时间、执行人/部门范围、任务到流程/目标/模板/节点、流程到目标/模板、工作计划到流程与类型。全部为 `CREATE INDEX IF NOT EXISTS`，没有表、字段、外键或数据迁移。
- 产品查询冷请求 159.2ms，完全相同查询的缓存命中为 2–3ms；缓存受数量和 10 秒 TTL 限制，产品写入立即清除。
- 模板使用汇总由重复 OR JOIN 改为 UNION CTE，隔离副本直接查询从约 203ms 降到 7–11ms。

## 目标中心验证器

既有失败并非目标业务逻辑失败，而是验证脚本依赖隔离子进程启动回环网络服务，在受限环境中被提前终止。验证器已改为直接验证目标服务契约、资源白名单、响应大小和权限路由，不再依赖本地监听端口。修复后 `npm run check` 全绿，目标中心不再出现“隔离子进程提前终止”。
