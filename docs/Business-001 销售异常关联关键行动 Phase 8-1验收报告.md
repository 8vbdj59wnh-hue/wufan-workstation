# Business-001 销售异常关联关键行动 Phase 8-1 验收报告

## 1. 实现内容

经营异常模块新增可展开详情。详情展示异常类型、对象、当前/对比周期、当前值、对比值、变化率，以及近7日与前7日的销售额、利润趋势摘要。

销售链接和产品异常在有现有 `workPlans.launch` 权限时显示“发起关键行动”。入口复用目标管理现有关键行动创建表单和模板权限，不建立第二套行动创建流程。

## 2. 创建方式

点击“发起关键行动”后：

1. 将异常上下文暂存到当前浏览器会话；
2. 进入现有目标管理关键行动表单；
3. 用户人工选择价值链模块、关键行动标准并填写信息；
4. 保存后生成状态为 `future` 的待发起关键行动。

本阶段不会自动启动标准流程，因此不会自动创建流程实例或任务。

## 3. 来源与关联快照

关键行动 `customFields` 保存：

- `source=sales_anomaly`；
- 产品异常保存 `productId`；
- 链接异常保存 `salesLinkId`；
- `anomalySnapshot` 保存异常类型、指标、严重等级、当前周期、对比周期、当前值、对比值、变化率和趋势摘要。

产品异常同时在现有产品选择器中预选对应产品。未来人工正式启动行动后，异常来源信息会随现有流程进入流程实例，并在关键行动详情显示“销售异常来源”。

## 4. 权限

入口展示和保存完全沿用 `workPlans.launch`、关键行动模板范围及目标管理原有权限。没有新增权限，也没有绕过模板可发起范围。

## 5. 隔离验证

在隔离数据库分别创建：

- 一条产品销售异常来源的待发起关键行动；
- 一条销售链接异常来源的待发起关键行动。

两条记录均可正确恢复 `sales_anomaly` 来源、关联对象和异常快照，状态为 `future`，且 `processInstanceId` 为空。
