# 经营管理基础升级验收报告（财务中心）

## 1. 建设结果

本阶段新增独立财务中心，形成“账单导入 → 科目识别 → 人工确认 → 财务事实 → 利润表 → 产品/链接/平台利润分析”的基础闭环。实现未修改 `products`、`sales_links`、`tasks` 等既有核心业务表，也未建立第二套产品、连接或任务模型。

## 2. 功能验证

### 财务首页与利润表

- 支持日、周、月周期查询。
- 统一计算销售收入、退款、实际收入、商品成本、毛利、经营费用、净利润和利润率。
- 支持产品、销售链接、平台三个维度的利润排行。

### 账单导入

- 支持 `.xlsx`、`.xls`、`.csv` 文件解析和文件哈希重复保护。
- 支持关键词科目规则、预览、未识别行人工选择财务类型和科目。
- 确认入账使用单一数据库事务；任意无效行会使整批失败，不产生部分数据。
- 可按 SKU 和平台商品 ID 复用现有产品、销售链接关系。

### 费用与规则

- 支持平台、广告、推广、人工、管理等费用事实查询。
- 支持科目规则新增、查询和删除。
- 支持独立财务审批权限及费用审批。

## 3. 权限验证

新增独立权限：

- `finance.view`：查看财务中心、利润表和分析。
- `finance.manage`：上传并确认账单、管理科目规则。
- `finance.approve`：审批财务记录。

财务权限不复用产品中心或数据中心权限。未登录访问财务 API 返回 `401`；管理员访问财务查询接口返回 `200`。

## 4. 数据库变化

新增独立表：

- `finance_import_batches`：账单导入批次与预览。
- `finance_rules`：科目关键词规则。
- `finance_entries`：已确认财务事实。

迁移使用 `CREATE TABLE/INDEX IF NOT EXISTS`，可重复执行。财务事实仅通过外键引用既有产品和销售链接，不修改核心表结构。

## 5. 隔离数据库验收

- 迁移连续执行两次成功。
- 测试账单 3 行：自动识别 2 行、人工归类 1 行，整体入账 3 行。
- 测试口径：收入 1000、成本 400、费用 100、净利润 500、利润率 50%。
- 财务记录审批成功。
- `PRAGMA integrity_check`：`ok`。
- `PRAGMA foreign_key_check`：无异常。
- `products`、`sales_links`、`tasks` 数量在验收前后保持一致。

## 6. 浏览器回归

- 一级导航可进入财务中心。
- 财务首页、利润表、费用管理、账单导入、规则设置正常显示。
- 管理员可见账单上传和规则管理入口。
- 空数据状态正常，无模拟财务数据。
- 浏览器控制台无错误。
- 产品中心、连接中心和任务中心的数据模型未修改。

## 7. 验收结论

财务中心基础能力达到本阶段提交条件。当前实现为经营利润分析基础层；财务凭证、预算、应收应付、发票、付款审批等专业财务能力不在本阶段范围，后续应继续使用独立财务权限与独立事实表渐进扩展。
