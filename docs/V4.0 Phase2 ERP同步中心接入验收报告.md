# 《V4.0 Phase2 ERP同步中心接入验收报告》

## 一、验收结论

V4.0 Phase2 已完成开发并通过隔离数据库验收。旺店通 ERP 货品/SKU 同步已接入统一数据同步中心，新执行链路使用 `data_sync_tasks → data_sync_batches → data_sync_logs / data_sync_exceptions`，历史 `erp_sync_runs` 与既有 ERP 主数据完整保留。

本次未修改 ERP 字段映射、`erp_goods`/`erp_skus` 数据模型，未自动创建产品，也未接入库存同步。

## 二、实现范围

1. 初始化统一任务“ERP货品同步”：
   - 任务代码：`erp_goods`
   - 同步类型：`wangdian_erp_goods`
   - 来源：旺店通 API
   - 接口：`goods.Goods.queryWithSpec`
   - 执行方式：自动 + 手动
   - 默认状态：暂停
2. 新增 ERP 同步适配器，将统一批次连接到原有、已验证的旺店通解析与 ERP 主数据提交能力。
3. 全量同步支持“创建批次—重新读取 API—生成预览—人工确认提交”。
4. 增量同步依据任务 `lastSuccessAt` 并复用原安全回看逻辑。
5. 每次预览生成新的 `data_sync_batches` 和独立 ERP 导入预览；历史预览可回看，仅最新有效预览可提交。
6. API调用、预览和完成结果写入统一日志；API、校验与提交异常写入统一异常中心。
7. 数据同步中心页面提供任务启停、全量/增量预览、预览确认、批次历史和异常查看。
8. 增加每分钟调度检查；只有管理员主动启用任务后才会按任务周期执行，默认不会自动同步。

## 三、历史兼容

- `erp_sync_runs`：保留且新统一同步不写入。
- `wangdian_goods_sync_logs`、`erp_import_batches`：继续作为既有底层解析审计记录，并通过来源ID与统一批次关联。
- `erp_goods`、`erp_skus`：沿用原模型及原精确编码幂等规则。
- 已有独立 ERP 同步页面和历史数据未删除。
