# 产品中心默认隐藏未建档产品验收报告

## 实现结果

产品中心首次打开时默认只查询存在 `products` 产品档案关系的 ERP SKU。筛选区域新增“显示未建档产品”开关，默认关闭；开启后通过后端参数 `includeUnarchived=true` 重新查询已建档与未建档数据。

## 查询规则

- `includeUnarchived` 缺失或为 `false`：SQL增加 `p.id IS NOT NULL`。
- `includeUnarchived=true`：不增加建档状态限制，返回全部符合其他条件的记录。
- 建档判断只使用当前 `product_erp_mappings → products` 关系及 `products.id`，没有使用ERP货品、图片、库存或销售链接代替产品档案。
- 搜索、筛选、排序、分页均在后端完成，没有前端加载全量后隐藏。

## 前端交互

- 开关默认关闭。
- 切换开关立即回到第一页并重新请求。
- 清空筛选后恢复默认关闭。
- SPA页面内继续使用产品中心现有筛选状态管理方式。
- 未建档SKU开启后继续沿用现有SKU详情及“创建产品档案”入口，没有新增详情逻辑。

## 隔离验证

使用隔离数据库副本验证：

- 默认查询：1661条，当前页未建档数量为0。
- 开启开关：6902条，分页总数重新计算。
- 未建档SKU `ZH0517-3`：关闭时搜索结果0条，开启时搜索结果1条。
- 第二页分页总数与第一页一致。
- 综合、销量、库存、资金占用、新品排序均保持1661条默认已建档范围。
- 生命周期筛选保持后端查询，并且结果只包含已建档产品。
- 已建档与未建档详情入口保持原行为。
- SQLite `integrity_check=ok`，`foreign_key_check` 无异常。
- `npm run check`、`git diff --check` 通过。

## 数据保护

未修改数据库结构、产品档案、ERP数据、SKU关系、库存、销售链接或产品详情数据结构。
