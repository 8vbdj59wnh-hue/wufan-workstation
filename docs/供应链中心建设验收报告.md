# 供应链中心建设验收报告

## 一、建设结论

供应链中心已完成基础建设，形成“供应商 → 产品/SKU → 采购 → 库存 → 品质 → 供应评价”的独立业务管理层。供应链业务关系引用现有产品和 ERP 事实，不修改 `products`、ERP 商品、ERP SKU 或销售链接的身份与同步规则。

本次仅完成开发、隔离验证和提交准备，不发布生产。

## 二、现有事实复用

- 产品对象：复用 `products`。
- ERP 规格：复用 `product_erp_mappings`。
- 当前库存、在途与成本：读取最新 `erp_fact_snapshots` / `product_erp_daily_snapshots`。
- 30 天销量：读取最新 `product_daily_snapshots.sales30d`。
- ERP 供应商兼容信息：保留 `erp_goods.primarySupplier` 等事实字段，不将其直接当作可维护供应商档案，也不反向覆盖。

## 三、新增能力

### 供应商管理

支持供应商编码、名称、联系方式、地址、合作状态与备注的维护，支持搜索和状态筛选。

### 产品供应关系

支持关联产品及可选 ERP 规格，记录供应商货号、供应成本、安全库存、交期、主供应关系和状态。产品级重复关系由唯一索引阻止。

### 采购管理

支持采购需求、采购计划和采购记录，保存产品明细、数量、成本、预计到货时间和到货状态。采购单与明细在同一事务中创建；标记全部到货时同步完成明细到货数量。

### 库存分析

基于正式快照分析当前库存、安全库存、在途、资金占用和 30 天销量，输出缺货、积压、健康及暂无事实四类状态，不新增或复制库存事实。

### 品质与评价

支持品质问题、改善状态、处理结果；支持按周期记录成本、交付、品质、配合四项评分及综合分。
