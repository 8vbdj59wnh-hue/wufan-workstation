# V4.0 Phase5真实销售导入验收报告

## 一、验收结论

V4.0 Phase5 已完成。真实销售 Excel 导入已接入统一数据同步中心，继续复用原 `connection_sku_sales_facts` 事实模型、唯一规则和利润字段，不创建链接或产品，不改变经营分析口径。

## 二、实现范围

- 初始化统一同步任务：`sales_fact_excel_import`，来源 Excel，人工执行，默认启用。
- 统一批次记录文件名、SHA-256、数据周期、行数、成功数、异常数和状态。
- 支持“上传 → 解析预览 → 关系及异常检查 → 人工确认 → 写入销售事实”。
- 相同文件 SHA-256 重复上传时返回已有批次，不重复生成事实。
- 统一异常中心收录文件/字段、周期、链接、平台 SKU、ERP SKU和重复事实异常。
- 数据同步中心增加真实销售上传、预览、确认和历史批次查看入口。
- 管理接口统一使用 `dataCenter.view` 与管理员双重服务端校验。

## 三、数据关联与保护

提交前按以下链路精确校验：

`platform + shop + platformGoodsId → sales_links → sales_link_skus（SKU编码精确匹配）→ erp_skus`

禁止名称或规格模糊匹配。链接、平台 SKU、ERP SKU任一缺失均进入异常中心并阻断提交。未修改 `sales_links`、`products`、产品关系、利润计算或销售事实结构。
