# 《V4.0 Phase4 库存同步中心验收报告》

## 一、验收结论

V4.0 Phase4 已完成开发并通过隔离数据库验收。旺店通库存接口 `wms.StockSpec.search2` 已接入统一数据同步中心，新同步执行使用统一任务、批次、日志、异常和调度机制，库存事实及ERP SKU日汇总继续写入既有模型。

本次未修改库存业务模型、链接库存查询、销售事实、补货或采购逻辑。

## 二、实现范围

1. 初始化“库存同步”任务：
   - 任务代码：`wangdian_inventory`
   - 来源：旺店通 API
   - 接口：`wms.StockSpec.search2`
   - 执行方式：自动 + 手动
   - 默认状态：暂停
2. 全量与增量同步统一使用 `data_sync_batches`。
3. 批次保存请求时间、业务日期、SKU范围、仓库范围、处理数量、异常及状态。
4. 全量同步采用“创建批次—调用API—生成预览—管理员确认—写入事实”的流程。
5. 增量同步使用任务 `lastSuccessAt`，并复用原库存同步的安全回看机制。
6. 每次读取生成新的预览批次；历史预览可查看，旧预览不可提交。
7. 到期任务接入统一调度器；任务默认暂停，不会未经确认自动运行。
8. 数据同步中心提供全量/增量预览、业务日期、SKU/仓库范围、批次历史和异常查看。

## 三、库存写入边界

- 仓库事实：`erp_sku_warehouse_inventory_facts`。
- ERP SKU日汇总：`erp_sku_inventory_daily_summaries`。
- 多仓库存按 `businessDate + erpSkuId + warehouseId` 幂等写入。
- 日汇总按ERP SKU聚合库存、可发库存、销量参考及库存成本。
- 成本采用有库存且存在成本的仓库库存金额加权。
- 不向链接复制库存。
- 不修改 `connection_sku_inventory_facts`。

## 四、统一异常

以下异常写入 `data_sync_exceptions`：

- `missing_sku_code`：接口缺少SKU编码；
- `missing_erp_sku`：SKU无法精确匹配ERP SKU；
- `missing_warehouse`：仓库身份字段不完整；
- `invalid_field`：库存或数值字段异常；
- `cost_permission`：接口未返回成本字段；
- API、分页及提交异常。

成本权限异常作为警告记录，不会伪造成本数据。
