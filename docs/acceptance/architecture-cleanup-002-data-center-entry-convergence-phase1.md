# Architecture Cleanup-002 经营数据中心入口收敛 Phase 1验收报告

验收日期：2026-08-20

## 一、结论

本阶段已完成入口和职责边界收敛，可以进入下一阶段验证或提交评审。

- 经营数据中心继续从一级导航隐藏，未删除页面、API或底层能力。
- `#dataCenter`、`#dataCenter/sync`、`#dataCenter/platform-goods-excel` 旧路由继续兼容。
- 平台货品导入已直接进入“链接中心 → 数据更新”，不再要求用户跳转经营数据中心。
- 系统设置新增“管理员数据中心”入口，用于承接同步管理能力。
- 经营查看权限与管理员同步权限已经分开。
- 未修改数据库、同步业务规则、导入API或数据模型。

## 二、修改范围

| 文件 | 修改内容 |
|---|---|
| `src/connectionCenterPage.js` | 在链接中心数据更新页直接呈现平台货品Excel导入、预览与确认能力；仅管理员数据中心权限可见。 |
| `src/services/connectionCenterService.js` | 从既有门面导出平台货品导入所需的现有调用能力。 |

| `server/index.js` | 数据同步中心接口统一使用管理员数据中心权限；经营查询接口继续使用经营查看权限。 |

## 三、入口变化

### 链接中心

“数据更新”页面内直接提供“平台货品导入”：

- 用途说明：用于建立平台店铺、链接和Link SKU身份。
- 继续使用既有 `platform_goods_excel_import` 任务和既有 preview/commit API。
- 只在进入数据更新页面时加载导入任务，不增加其他链接中心页面的启动请求。

### 系统设置

新增“管理员数据中心”入口，作为同步任务、批次、日志和异常能力的管理员归属位置。本阶段未重构同步页面和后端服务。

### 经营数据中心

- 一级导航仍为隐藏状态。
- 旧URL不删除、不重定向失效。
- 有对应管理员权限时，旧同步URL仍能进入原同步能力；无权限时回落到经营视图。

## 四、权限边界

| 能力 | 权限 |
|---|---|
| 经营驾驶舱、趋势、滞销、资金占用 | `dataCenter.view` |
| 同步任务、同步批次、平台货品导入、同步异常处理 | `settings.manageAdminDataCenter` + 管理员身份 |

验证结果：

- 管理员：可进入管理员数据中心和平台货品导入。
- 仅有经营权限的运营人员：可查看经营数据，不可进入同步管理。
- 普通用户：不可见管理员同步入口。

## 五、兼容与数据保护

- 平台货品导入 API 路径、解析、预览、确认和写入逻辑均未修改。
- 旧 dataCenter 路由仍保留。
- 数据同步底层能力未删除。
- 本阶段未执行数据库写入或迁移。
