# 关键行动倒计时功能验收报告

## 一、实现结果

- 关键行动卡片新增截止时间与剩余/超时时间展示。
- 关键行动列表统一使用同一倒计时格式。
- 关键行动详情顶部新增状态、负责人、截止时间和时间状态摘要。
- 页面停留期间每分钟自动刷新时间展示。
- 已完成、已取消、已终止的关键行动停止累计超时并显示终态。

## 二、展示规则

- 未到截止时间：显示“剩余 X天X小时”或“剩余 X小时X分钟”。
- 超过截止时间：显示“已超时 X天X小时”或“已超时 X小时X分钟”，并使用红色高亮。
- 未设置截止时间：显示“未设置截止时间”。
- 终态行动：显示“已完成”“已取消”或“已终止”。
