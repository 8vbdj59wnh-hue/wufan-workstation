# Business-001 ERP SKU用途治理工作台 Phase 3-2G 验收报告

## 一、验收结论

Phase 3-2G 已完成。工作台治理对象为 ERP SKU，销售日报明细仅作为审核证据。人工确认只写入 `erp_sku_business_usages`，不创建关系、不修改 ERP SKU、不写销售日报事实。

## 二、页面能力

- 入口：经营链接中心 → ERP SKU用途治理（仅具备链接管理/产品编辑权限的管理员可见）。
- 顶部统计：待确认 ERP SKU、影响销售额、影响利润、已确认数量、身份待处理编码。
- 列表：ERP SKU 编码、名称、规格、建议用途、当前用途、状态、优先级、影响行数、链接SKU数量、销售额、利润和日期范围。
- 筛选：未确认/已确认/冲突、建议用途、P0/P1/P2、编码或名称搜索。
- 详情：ERP信息、建议证据、影响摘要、分页销售明细和完整用途审计记录。
- 操作：人工选择用途并填写确认说明。

## 三、查询能力

新增 ERP SKU 聚合查询、详情查询和确认接口。最近一次销售日报预览作为影响证据来源，列表和销售证据均分页返回。

真实隔离数据得到 376 个待确认 ERP SKU。另有 1 个无法落到 `erp_skus.id` 的编码，被单独计入身份待处理，不会伪造成用途治理对象。

## 四、确认与审计

- 支持 `product`、`accounting_auxiliary`、`shipping_adjustment`、`other_adjustment`。
- 确认前校验 ERP SKU、用途、审核人和确认说明。
- 同用途重复确认幂等，不新增重复 active 记录。
- 用途替换在同一事务中把旧 active 记录置为 superseded，再创建新的 active 记录。
- active 记录保存 `manual_confirmation`、审核人、审核时间、说明和被替代记录。
