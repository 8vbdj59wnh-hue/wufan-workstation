# Business-001 产品中心销售日报接入 Phase 5-3 验收报告

## 1. 页面接入

Product Workspace概览新增标准模块 `product_daily_sales`，展示产品维度的日报经营表现：

- 周期；
- 销售额；
- 利润；
- 销量；
- 利润率；
- 每日销售额、利润、销量趋势；
- 销售链接贡献。

支持近7日、近30日切换。模块随已建档产品详情加载；未建档ERP SKU明确提示需先建立产品档案，现有ERP SKU日报事实不会被强制归入产品。

无事实时显示“暂无数据”。存在事实且指标真实为0时保留0。趋势缺失日期保留`noData`并显示“暂无数据”，不补0。

## 2. 查询调用与聚合规则

页面展示服务只调用：

- `QueryDailySalesSummary`
- `QueryDailySalesTrend`

产品维度严格通过日报事实的`erpSkuId`与`product_erp_mappings.currentState='active'`归入`products.id`。

为满足链接贡献的一次性查询，`QueryDailySalesSummary`产品维度支持可选的销售链接分组返回。分组仍直接聚合原有ERP SKU粒度日报事实：

- 不根据mapping quantity分摊；
- 不根据Combo重算；
- 不读取旧`connection_sku_sales_facts`；
- 页面和产品展示服务不直接读取日报事实表。

产品展示服务仅按Capability返回的`salesLinkId`批量读取链接名称、平台和店铺，不参与销售计算。

## 3. 隔离验证结果

使用Phase 4隔离数据库副本验证，日期范围为2026-07-09至2026-08-09，共171条日报事实。

真实产品验证结果：

- 82条产品日报事实；
- 销量217；
- 销售额10,184.34；
- 成本6,128.0163；
- 利润3,719.5137；
- 利润率36.5219%；
- 11条销售链接贡献；
- 链接贡献销售额合计10,184.34，与产品汇总一致；
- 链接贡献利润合计与产品汇总一致；
- 趋势返回完整32日，缺失日期保持`null/noData`；
- 重复查询结果稳定。

无数据产品验证：

- `hasData=false`；
- 销售指标为`null`；
- 链接贡献为空；
- 趋势保持无数据语义。

Phase 4的171条事实均已有有效产品映射，因此隔离样本中没有可单独抽取的“未映射ERP SKU事实”。已验证查询仅在产品维度读取有效映射，且不会删除、修改或迁移未映射事实；事实表前后171条及SHA-256完全一致。未映射ERP SKU仍可继续通过ERP SKU维度Capability独立查询。

## 4. 性能

- 单产品详情完整日报查询共5条SQL；
- 产品汇总和链接贡献在数据库端一次聚合；
- 链接身份一次批量读取；
- 不逐ERP SKU查询；
- 不逐链接调用汇总Capability；
- 页面不存在N+1请求。

## 5. 数据保护

隔离验证前后SHA-256摘要一致：

- 日报事实：171条，不变；
- 链接SKU—ERP SKU mappings：不变；
- ERP SKU：不变；
- 产品映射：不变。

数据库检查：

- `integrity_check`: `ok`
- `foreign_key_check`: 0项异常

本阶段未修改日报事实、产品映射、ERP SKU、链接关系或Combo，也未增加新的销售事实计算口径。

## 6. 结论

产品中心已经具备日报事实口径的产品销售概览、每日趋势和销售链接贡献展示能力。查询保持ERP SKU事实粒度和有效产品映射边界，可进入后续经营页面统一口径验证阶段。
