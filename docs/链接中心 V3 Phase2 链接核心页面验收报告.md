详情页新增并启用以下经营区域：

1. 基础与经营概览：主图、标题、平台、店铺、商品ID、平台链接，以及ERP销售核心指标和平台表现。
2. ERP真实销售：按导入周期识别日/周/月粒度，展示发货销量、销售金额、成本和利润。
3. SKU销售分析：按最新ERP销售周期展示SKU销量、销售额及销售贡献占比。
4. 产品关联：展示产品图片、名称、编码及关联SKU数，可进入产品详情。
5. 库存供应：展示当前库存、可售库存、销售速度、库存天数和缺货/高低库存风险。

原经营动作、经营趋势、体检、改善和对标能力继续保留。
