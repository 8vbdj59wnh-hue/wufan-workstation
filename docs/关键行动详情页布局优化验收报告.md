# 关键行动详情页布局优化验收报告

关键行动详情页布局优化已完成，标准步骤任务已调整为详情页第一内容区域，并升级为以执行进度、状态和责任人为核心的步骤卡片。原关键行动、流程节点和任务关系未改变，具备提交条件。

调整后的详情页顺序：

1. 标准步骤任务；
2. 关键行动信息；
3. 过程记录；
4. 结果与复盘。

## 三、标准步骤任务

步骤卡片按照原 `process_template_nodes` 与 `tasks.processInstanceId/processNodeId` 关系聚合，不建立新的任务模型。

每个步骤展示：

- 步骤编号和步骤名称；
- 任务总数和完成数量；
- 当前业务状态；
- 当前负责人和执行人；
- 开始时间和截止时间；
- 数字进度与可视化进度条；
- 步骤下的任务及任务详情入口。

可编辑关键行动继续保留原负责人、执行人和截止时间调整能力。
