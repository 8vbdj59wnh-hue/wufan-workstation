# 模板中心版本化管理验收报告

## 一、验收结论

V2.1 模板中心版本化管理升级已完成，具备提交条件，未发布。

四类企业标准资产已统一进入版本生命周期：

- 视觉模板；
- 关键行动库；
- 表单模板；
- 任务操作说明书。

现有模板新增后建立 `V1.0`；内容修改通过“迭代”生成小版本或大版本，不再允许通用资源接口直接覆盖。历史内容、版本状态、修改说明、创建人、创建时间和使用次数均保留。

## 二、版本模型

新增 `template_asset_versions` 版本事实表，保存：

- 模板类型和模板主体 ID；
- 版本号、主版本号、次版本号；
- `active / superseded / inactive / archived` 状态；
- 完整版本内容；
- 修改说明、创建人和时间；
- 启用、停用和归档时间。

数据库使用唯一约束保证同一模板主体的版本号不重复，并使用唯一部分索引保证最多只有一个启用版本。迁移与历史模板初始化均为幂等处理。

## 三、生命周期验证

在独立 SQLite 数据库完成验证：

|场景|结果|
|-|-|
|新增模板建立 V1.0|通过|
|小版本迭代 V1.0 → V1.1|通过|
|大版本迭代 V1.1 → V2.0|通过|
|迭代后旧版本完整保留|通过|
|历史版本重新启用并恢复业务内容|通过|
|同一模板只有一个启用版本|通过|
|停用当前版本|通过|
|归档版本且保留历史|通过|
|重复迁移|通过|

直接调用旧通用更新入口修改四类模板时，后端返回冲突提示，要求使用版本迭代接口。

## 四、页面验证

模板中心已验证：

- 四个独立分类入口正常；
- 视觉模板卡片显示当前版本、状态、迭代与版本历史；
- 关键行动库保留价值链分类和原展示结构，并显示当前版本、迭代与版本历史；
- 表单模板保留原表单设计和预览能力，并显示版本操作；
- 任务操作说明书保留原方法论数据和详情，并增加当前版本与迭代入口；
- 版本历史可查看完整历史内容、变化字段、修改说明、创建信息和使用次数；
- 启用、停用和归档入口正常显示；
- 从模板中心切换关键行动、任务中心再返回模板中心正常，无页面阻塞或读取错误。

页面验证未执行任何模板内容修改或业务流程写入。

## 五、业务兼容

- 关键行动模板主体 ID 不变，原关键行动发起和流程绑定关系不变；
- 任务模板、流程节点和任务生成关系不变；
- 表单主体 ID 与 `standardWorkId` 引用不变；
- 方法论/操作说明书主体 ID、流程节点和任务模板引用不变；
- 启用历史版本时更新原模板主体内容，使已有读取方继续通过原关系获得当前生效版本；
- 停用和归档不删除模板主体、历史版本或使用记录。
