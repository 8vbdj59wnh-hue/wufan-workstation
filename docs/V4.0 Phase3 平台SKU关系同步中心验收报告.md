# 《V4.0 Phase3 平台SKU关系同步中心验收报告》

## 一、验收结论

V4.0 Phase3 已完成开发并通过隔离数据库验收。旺店通 `goods.ApiGoods.search` 已接入统一数据同步中心，形成“同步任务—统一批次—旺店通适配器—平台SKU关系—ERP SKU—既有产品映射”的受控链路。

同步仅补充现有链接的 SKU 关系，不创建链接、不创建产品、不修改链接身份、销售事实或库存逻辑。

## 二、实现内容

1. 初始化“平台货品关系同步”任务：
   - 任务代码：`wangdian_platform_goods`
   - 来源：旺店通 API
   - 接口：`goods.ApiGoods.search`
   - 执行方式：自动 + 手动
   - 默认状态：暂停
2. 全量及增量执行统一使用 `data_sync_batches`，记录时间、平台/店铺范围、数量及异常。
3. 每次读取均创建独立预览批次；旧预览保留为历史版本，只有当前有效预览可提交。
4. 旺店通店铺编号必须先映射系统 `shopId`；未知店铺阻断提交。
5. 链接仅按 `shopId + platformGoodsId` 精确查找，不使用旺店通商品ID替换或创建链接身份。
6. 平台SKU写入 `sales_link_skus`，保存平台SKU ID、编码、规格、价格及接口提供的平台库存字段。
7. ERP SKU 仅按 `merchant_no → erp_skus.merchantSkuCode` 精确匹配。
8. 若既有 `product_erp_mappings` 可用，则沿用产品映射；否则保留 `erpSkuId`，不创建产品。
9. 手工产品绑定优先级保持不变，自动同步不会覆盖人工绑定。
10. 自动调度能力已接入，但任务默认暂停。

## 三、统一异常

以下异常写入 `data_sync_exceptions`：

- `unknown_shop`：旺店通店铺未映射；
- `missing_platform_goods`：系统中不存在对应链接资产；
- `missing_erp_sku`：ERP SKU不存在；
- `missing_merchant_no`：商家编码为空；
- `ambiguous_erp_sku`：精确编码出现多候选时阻断；
- `duplicate_platform_sku`：同批次平台SKU身份重复；
- `platform_restricted`：淘系接口返回范围限制；
- API、格式和提交异常。

## 四、历史兼容与数据保护

- 保留现有 `sales_links` 和 `sales_link_skus`，不删除历史关系。
- 为 `sales_link_skus` 增加可空 `erpSkuId`，历史数据无需重建。
- 保留人工产品关联，不覆盖 `matched_manual` / `manual` 关系。
- `sales_links`、`products`、销售事实及库存事实均不被本同步创建或修改。
- 店铺映射独立保存，平台身份继续使用 `platform + shopId + platformGoodsId`。
