# Performance-001 懒加载效果评估 Phase 3E 验收报告

## 1. 评估边界

本次仅测量和分析，未修改业务代码、数据库或迁移其他模块。使用当前未发布工作区源码、本机静态 HTTP 服务和浏览器冷启动资源清单进行测量。

本地测试环境没有已登录会话和业务后端，因此浏览器停在登录页；登录后的接口请求数量和接口耗时不能据此伪装为驾驶舱实测值。本文将前端资源实测与静态依赖闭包分开记录。

## 2. 启动性能对比

优化前基线：63 个 JS 模块、2.12 MB 源码。

当前结果：

| 指标 | 当前值 | 说明 |
|---|---:|---|
| 浏览器观察到的 JS 请求 | 64 | 按完整 URL 统计；同一文件不同版本参数会形成重复请求 |
| 去重后的首屏静态 JS 闭包 | 52 个 | 1,663,159 bytes（1.59 MiB） |
| CSS 请求 | 2 | `styles.css`、`productWorkspace.css` |
| CSS 主文件源码 | 296,333 bytes | 本地无压缩静态服务 |
| 接口请求 | 0 | 当前本地浏览器未登录，未进入登录后驾驶舱初始化 |
| 全部 `src` JS 库存 | 84 个 | 2,197,244 bytes（2.10 MiB） |

与优化前 63 模块相比，首屏静态闭包为 52 个，减少 11 个（17.5%）；源码口径由 2.12 MB 降至约 1.59 MiB，减少约 0.53 MB（约25%）。

但浏览器仍观察到64个脚本请求，原因是同一模块被不同 `?v=` 参数重复引用。这会削弱模块数下降带来的请求收益。

## 3. 路由首次加载

| 路由 | 首次新增模块 | 首次新增源码 | 主页面文件本机请求 | 再次进入 |
|---|---:|---:|---:|---|
| 任务中心 | 1 | 123 bytes | `tasksPage.js` 286,545 bytes / 1.23 ms | adapter缓存命中 |
| 链接中心 | 19 | 321,655 bytes | `connectionCenterPage.js` 261,830 bytes / 1.12 ms | adapter缓存命中 |
| 产品中心 | 7 | 196,754 bytes | `productCenterPage.js` 178,163 bytes / 1.25 ms | adapter缓存命中 |

说明：任务中心动态入口只有123字节，是因为真正的 `src/tasksPage.js` 已被其他首屏模块静态引入。因此“进入任务中心才请求任务业务模块”尚未真实成立；当前只延迟了包装入口。

链接中心和产品中心的业务实现及专属依赖已真实退出首屏闭包，分别延迟约314 KiB和192 KiB源码。

## 4. 静态依赖检查

`main.js` 已不再静态引用：

- `tasksPage`；
- `connectionCenterPage`；
- `productCenterPage`。

但发现隐藏静态依赖：

- `goalsPage.js` → `tasksPage.js`（使用 `selectTask`）；
- `scheduleBoardPage.js` → `tasksPage.js`（使用 `selectTask`）；
- `processesPage.js` → `tasksPage.js`（使用 `selectTask`）。

因此任务中心大文件仍在首屏加载。链接中心和产品中心未发现同类隐藏静态回流。

其他仍在首屏静态加载的大型业务模块包括目标、流程、设置、排期、数据中心、财务中心、供应链、客户中心、AI助手、模板中心及经营驾驶舱。这些不属于 Phase 3E 修改范围。

| 场景 | 结果 |

| 权限判断代码路径保持不变 | 通过 |
| hash路由映射保持不变 | 通过 |
| 通知跳转按需加载任务adapter | 通过 |

受本地未登录状态限制，本轮未生成登录后真实业务接口耗时数据；已有专项测试已覆盖调用契约和导航稳定性。

## 6. 结论

Phase 3A–3D 已产生真实但不完整的收益：

- 链接中心与产品中心已真正从首屏移除，合计延迟约518,409 bytes源码；
- 首屏静态闭包较原基线减少约25%源码体积；
- 任务中心因跨模块直接导入 `selectTask`，其286,545字节主体仍在首屏，Phase 3B的性能目标只部分达成；
- 不同版本查询参数造成重复模块请求，是当前请求数仍高于基线模块数的另一原因。

建议下一步只做专项设计：把跨模块 `selectTask` 下沉为轻量导航/action入口，并统一相同文件的版本参数。未建议在本阶段继续迁移其他模块。
