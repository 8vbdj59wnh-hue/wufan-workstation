# 驾驶舱管理视角今日概览验收报告

## 一、完成内容

- 管理驾驶舱原“工作统计”页签更名为“今日概览”。
- 今日概览升级为四张可点击统计卡片：
  - 新发起行动数；
  - 完成行动数；
  - 新增异常数；
  - 完成改善数。
- 默认展示“新发起行动”明细，点击其他卡片动态切换下方列表。
- 全部统计直接读取现有业务数据，未新增统计表。

## 二、数据口径

| 指标 | 数据来源与当天判断 |
|---|---|
| 新发起行动 | `processInstances.createdAt` 为当天 |
| 完成行动 | 关键行动状态为完成，且 `completedAt` 为当天 |
| 新增异常 | 当天创建的问题记录，以及当天形成的任务超时、返工、验收退回记录 |
| 完成改善 | 现有改善工作当天完成，复用改善验证结果 |

统计继续遵守管理驾驶舱原有人员/部门数据范围。

## 三、列表字段

- 新发起行动：行动名称、负责人、发起时间、当前状态。
- 完成行动：行动名称、完成人、完成时间、结果状态。
- 新增异常：异常名称、来源、负责人、当前状态。
- 完成改善：改善项目名称、负责人、完成时间、改善结果。
