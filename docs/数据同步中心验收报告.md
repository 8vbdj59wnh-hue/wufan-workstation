# 数据同步中心验收报告

## 一、建设结论

V4.0 Phase1 数据同步中心基础框架已完成。系统已将长期同步任务、单次执行批次、过程日志和异常记录拆分为独立层级，并在经营数据中心增加管理员专属“数据同步”入口。

本阶段只建立统一框架，没有改写现有旺店通、Excel、库存、平台关系或ERP字段映射逻辑。

## 二、同步任务模型

新增 `data_sync_tasks`，保存同步类型、数据来源、接口方法、传输方式、执行方式、默认同步模式、调度周期、最近成功时间、下次执行时间和启用状态。

初始化五类任务：

1. ERP货品同步：旺店通 `goods.Goods.queryWithSpec`；
2. 平台货品关系同步：旺店通 `goods.ApiGoods.search`；
3. 库存同步：旺店通 `wms.StockSpec.search2`；
4. 平台经营数据导入：Excel人工导入；
5. 真实销售导入：Excel人工导入。

三项API任务支持自动与手动两种执行概念，默认暂停，避免框架初始化后误触发外部同步；两项Excel任务保持人工模式。

## 三、同步批次模型

新增 `data_sync_batches`，一次执行对应一个批次，记录：

- 自动或手动触发；
- 全量或增量模式；
- 等待、执行中、成功、部分成功、失败状态；
- 请求时间范围；
- 总量、新增、更新、失效和异常数量；
- 来源业务批次关联；
- 开始、结束、错误和操作人。

已提供等待、启动、完成的标准生命周期服务接口，供后续各同步适配器接入。

## 四、日志和异常

新增：

- `data_sync_logs`：记录批次排队、启动、完成和详细上下文；
- `data_sync_exceptions`：统一保存API失败、权限、字段、匹配和冲突类异常，并支持人工处理状态与说明。

## 五、管理页面

经营数据中心新增“数据同步”页，管理员可以查看：

- 同步任务及启用/暂停状态；
- 来源、执行方式、默认模式和计划周期；
- 最近同步与下次执行；
- 单次执行历史；
- 统一异常列表；
- 历史ERP同步和历史导入批次数量。

管理员可以启用、暂停任务，并创建手动执行批次。当前Phase1只建立执行队列，具体旺店通和Excel适配器仍沿用原入口，后续阶段再接入统一执行器。

## 六、权限验证

- 数据同步中心所有服务端接口同时要求 `dataCenter.view` 和管理员身份；
- 普通运营不显示数据同步页签；
- 普通运营直接调用接口返回403；
- 现有数据中心分析权限保持不变。

## 七、历史兼容

- 不修改 `erp_sync_runs`；
- 不修改 `erp_import_batches`；
- 不修改 `wangdian_goods_sync_logs`；
- 不迁移或重写历史同步数据；
- 统一中心只读取历史数量作为兼容概览；
- 原ERP每日同步及导入入口继续工作。

## 八、隔离验证结果

- 初始化同步任务：5项；
- API任务：3项；
- Excel人工任务：2项；
- 手动批次生命周期：等待 → 执行中 → 部分成功，通过；
- 批次日志：正常；
- 异常生成与人工解决：正常；
- 重复初始化：任务仍为5项，迁移幂等；
- SQLite `integrity_check`：`ok`；
- SQLite `foreign_key_check`：0项；
- 旺店通ERP货品/SKU既有回归脚本：通过；
- `npm run check`：通过；
- `git diff --check`：通过。

## 九、限制与后续

本阶段没有启动后台定时调度器，也没有把原有同步适配器改接到统一批次执行器。API任务默认暂停；“立即执行”当前创建标准等待批次，不会绕过原同步流程直接写入业务数据。

后续建议按同步类型逐一接入统一执行器，并在每个适配器独立验收后再启用自动调度。

## 十、最终结论

同步任务、执行批次、日志、异常和权限边界已建立，自动/手动、全量/增量概念已分离，历史同步保持兼容。V4.0 Phase1 数据同步中心基础框架验收通过。
