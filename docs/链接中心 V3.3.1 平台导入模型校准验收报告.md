# 链接中心 V3.3.1 平台导入模型校准验收报告

## 一、验收结论

本次校准通过。平台导出链接经营表已统一按 `platform_link_operations` 处理，一次确认导入在同一事务中完成：

1. 创建或更新 `sales_links`；
2. 创建或复用一对一的 `connection_profiles`；
3. 创建平台商品身份映射；
4. 写入对应周期的 `connection_period_snapshots`。

业务上不再区分“销售链接”和“经营链接”：二者都是同一链接资产。`sales_links` 保存平台销售身份，`connection_profiles` 保存该资产的经营管理属性，这是同一资产的技术分层，不是两套链接模型。

## 二、本次校准内容

- 数据中心保留统一“数据导入”主入口，移除独立“经营数据导入”和“待关联数据”主导航，避免形成第二套平台导入流程。
- 链接资产页、空状态和受限创建接口统一提示使用“平台链接经营导入”。
- 旧生意参谋导入代码和历史待识别数据仅作为历史批次兼容能力保留，不删除历史数据、不改变历史引用。
- 增强隔离验收脚本：逐行验证平台数据确认后均存在销售链接、经营档案和周期事实。
