仅限未策划、未关联行动、未进入执行的草稿需求。保留管理权限、助手专属路径授权、最新revision、整批事务、幂等冲突保护。前后需求、产品及操作者审计持久保存在 request_batches.result。无需数据库迁移或历史数据重写。
