# ERP同步行级异常隔离验收报告

## 一、验收结论

Business-001 ERP货品同步已由“任一主数据冲突阻断整批”调整为“SKU行级隔离”。`spec_no`作为ERP SKU唯一业务身份，`goods_id`只保留在来源审计信息中，不参与SKU主身份判断。

结论：通过隔离数据库验收，未修改生产数据库，未执行生产同步。

## 二、实现范围

- 正常、唯一且处于有效状态的`spec_no`写入`erp_skus`。
- 同一`spec_no`对应多个`goods_no`、SKU历史归属冲突、停用SKU、缺少核心身份的记录按SKU身份隔离，不写入ERP业务主表。
- 隔离明细写入`data_sync_exceptions`，记录`spec_no`、`goods_no`、`goods_id`、源行号及冲突原因。
- 图片下载失败、货品名称缺失、历史`goods_id`重复及产品多匹配等非核心问题作为warning，允许其他主数据继续处理。
- 只有API读取失败、没有任何可解析SKU身份、数据库写入失败或事务异常才阻断整批。
- ERP同步不创建`products`，也不新增或更新`product_erp_mappings`。
- 提交页展示SKU总数、可导入数量、异常跳过数量和警告数量；存在行级异常时仍允许管理员确认提交。
