# 生产服务器路径配置

生产运行路径由 `server/productionPaths.cjs` 统一解析。PM2、服务端数据库保护、正式发布和生产备份必须使用相同的环境变量，禁止在代码中按用户名选择路径。

必填配置：

- `WUFAN_PROJECT_DIR`
- `WUFAN_DATA_ROOT`
- `WUFAN_DB_PATH`
- `WUFAN_DB_BASELINE_PATH`
- `WUFAN_UPLOADS_PATH`
- `WUFAN_AUTH_SECRET_PATH`
- `WUFAN_RELEASE_ROOT`

执行独立生产备份时还必须配置 `WUFAN_BACKUP_ROOT`。PM2 日志可通过 `WUFAN_PM2_LOG_ROOT` 指定；未指定时使用当前服务器账户的 `~/.pm2/logs`，不绑定用户名。

完整示例见 `config/production.env.example`。旺店通凭据和 `auth.secret` 内容只能从服务器受保护环境或持久文件继承，不得写入示例文件或 Git。

## 安全规则

1. 所有生产路径必须是绝对路径，并通过现存父目录的真实路径规范化，防止 `..` 和软链接绕过。
2. 项目、数据、发布、备份及日志路径不得位于临时目录或常见网络卷。
3. 数据库、业务基线、附件和登录密钥必须位于 `WUFAN_DATA_ROOT` 内。
4. 数据根目录必须与 Git 项目目录分离，数据库不得位于仓库内。
5. 缺少数据库、基线、附件目录或登录密钥时，生产发布明确失败；生产服务不会退回开发数据库，也不会自动生成新的登录密钥。
6. 路径参数化不改变数据库重置锁、迁移预演、在线备份、业务基线、磁盘空间、维护模式、纯快进、定向重启和人工浏览器验收门禁。

## 迁移前检查

新服务器首次预演前，应由管理员在服务器本机完成以下准备，但不得启动正式服务：

1. 按示例配置 `wufan001` 路径，并确认目录归属和权限。
2. 通过受控迁移流程放置数据库、基线、附件和原有 `auth.secret`；不能生成空数据库或替换登录密钥。
3. 运行 `scripts/resolve-production-paths.mjs` 检查规范化结果。
4. 对数据库执行只读完整性与外键检查，并核对业务基线。
5. 使用隔离发布包执行预切换 dry-run；不得启动 PM2、不得执行真实迁移。
6. 完成人工浏览器、登录、附件和关键业务读取验收后，再单独申请正式切换。

旧路径只允许出现在历史验收记录和 `config/production.env.example` 的旧服务器配置示例中，不参与运行时默认值。
