# 内容中心接入说明

本次接入目录：`dev-runtime-current`。在原有未提交的学习中心改动上增量接入，没有覆盖其他模块。一级菜单位于产品中心之后、学习中心之前。入口 `/#contentCenter`，兼容 `/#content-center`。

## 已接入功能

- 公司品牌 → 账号 → 栏目联动；内容日历、两小时时间格、月历、周历、账号快捷筛选。
- 候选池、单条笔记、批量笔记需求、生成状态和同 ID 转排期。
- 图文/视频形式、多货品编码、模板关联、图片上传和已有图片库。
- 保留原 ID、revision、时间戳、图片 BLOB、版本冲突、批量事务和失败回滚。
- 货品编码通过工作站 `erp_goods.goodsCode` 精确匹配，未知或歧义保留输入并提示。不会创建工作站产品或将历史 UUID 当作工作站产品 ID。
- 内容中心 API 使用 `/api/content-center/*`，经过工作站现有登录；图片和导出同样需要授权。前端复用现有日历界面，通过工作站页面内的 iframe 隔离样式，并调用统一认证请求。没有额外运行原迁移包的独立服务。
- 存储适配为工作站已有 `better-sqlite3`，没有增加第三方依赖或 Node 24 要求。

## 权限边界

系统设置的权限目录增加“内容中心（公司共享）”：

| 权限 | 用途 |
| --- | --- |
| contentCenter.view | 查看全公司品牌内容、候选、模板和图片 |
| contentCenter.manage | 创建及修改内容、排期、品牌账号栏目、模板和图片 |
| contentCenter.export | 导出完整内容备份 |

管理和导出依赖查看权限。普通旧账号不自动获得新模块权限，管理员按岗位配置。该模块的数据为公司共享资源，此处的“查看”明确授予公司内容范围，不按个人任务的 self/department 范围猜测品牌归属。产品查询另需 `products.view`。历史产品管理接口没有接入。

## 正式切换与回滚

本次未发布生产。正式切换时先暂停旧端录入并获取最终一致快照，备份工作站当前代码和数据库，再将内容库迁移到新的、尚不存在的目标路径：

```sh
node scripts/migrate-content-center.mjs /绝对路径/banran.sqlite /绝对路径/content-center-新版本.sqlite
```

脚本在线备份、核对全表哈希和完整性，并拒绝覆盖已存在的目标。不要仅复制正在写入的 SQLite 主文件。完成核对后，将工作站运行配置中的 `WUFAN_CONTENT_DB_PATH` 指向新文件，重启后端及前端并分配内容中心权限。前端通过现有部署方式提供 `src`、`shared`、`public`，私有数据目录不得对外静态暴露。

回滚时暂停新端录入，先为新内容库做一致备份，恢复旧代码和此前环境配置，再重启服务。内容策划仍在独立库；发起行动会写入工作站主库的工作计划、行动、任务、产品关系及来源关联表，因此应同时备份主库、内容库与上传文件；若新端已产生内容，不得直接覆盖，应保留该库供差异合并。界面 JSON 导出用于完整资料留存，部署恢复以 SQLite 一致备份为准。


## 内容策划与发布行动联动（本轮优化）

- 内容编辑复用发布行动的 ERP SKU 选择器和笔记模板选择器，直接引用产品中心、模板中心资料。历史货品编码单独保留，不将迁移 UUID 当作工作站产品 ID。产品连续搜索后已选项保留。
- 策划显式关联工作站发布账号，以 ID 区分同名账号。单条候选笔记可填写计划日期与时间。
- 详情“发起发布行动”进入已有原生发起表单，带入标题、初稿、话题、产品、模板、账号及分钟级发布时间；选择对齐目标并确认后才提交。必须存在启用的发布内容笔记标准及流程步骤，沿用既有执行和审核规则。
- 主库 content_center_action_links 以 noteId 唯一关联行动，事务内保存来源与策划快照。重复提交返回已有行动；版本变化要求重新预览。发起后的策划修改不会覆盖执行内容。
- 详情回显当前步骤、执行人和发布凭证，并可打开关联行动；行动详情可返回来源策划。只有完成发布步骤并回填有效链接才显示已发布。重新进入详情读取最新进度。
- 参考图复制为工作站附件后跟随行动保存，需要 uploads.upload 权限。关联产品需要 products.view；模板遵循原有模板查看权限；发起还需要内容管理、目标查看和对应行动发起权限。
- 本轮为单条策划联动，未增加批量发起，也未部署生产。

验证：25 项内容中心测试、13 项权限回归和 6 项公共表单测试通过，语法检查通过。浏览器测试使用 /tmp/wufan-content-center-preview/content-integration.sqlite 独立内容副本及同目录 workstation.db；验收 SKU、模板、笔记和行动均属于测试资料。

浏览器端到端验收：测试笔记成功发起 KA-202609-0001，沿用标准生成 6 个任务；返回内容详情显示“提交内容需求 · 赵磊”。核对行动的 ERP SKU、模板、账号 ID、10:30 发布时间及来源快照。修改测试策划后详情出现快照差异提示，行动原文保持不变。测试库原始默认数据没有正式发布内容笔记标准，验收仅在隔离库配置了该标准并绑定已有内容发布流程。


## 内容需求与内容候选拆分

一级内容中心下提供独立的“内容需求”“内容候选”页签。内容需求承接单条选题和批量需求，正文可暂空；补齐标题、正文和笔记形式后，通过“存入内容候选”进入候选列表。批量需求沿用已生成内容必须具有话题的校验。候选可继续关联产品、模板、发布账号，并进入排期和发布行动。

contentStage 在原内容记录中保存 request/candidate，转换不复制记录、不更换 ID，所有关联及备注随记录保留。未填写阶段的历史资料按完整程度区分显示，不在读取时修改原数据；批量未生成和需调整资料归入需求。显式需求保存完整正文仍停留在需求，直到存入候选。需求不能直接发起发布行动，显式需求不能直接转排期。

内容需求可编辑列表现仅提供想法、关联产品、关联模板、发布时间四项。产品以 ERP SKU 编码精确匹配，显示主图（缺图明确提示）、名称和编码，支持多产品及移除；通过行保存持久化工作站关联 ID。无法匹配或重复编码时保留输入并提示。模板读取模板中心的笔记模板，沿用权限和行版本校验。浏览器已验证编码匹配、关联草稿及撤销。

批量提交需求功能已移除：取消入口、录入弹窗及 POST /requests/batch 接口。历史批量来源记录仍可逐条查看、编辑和转入内容候选。

内容日历接入 GET /calendar-actions：读取当前权限范围内所有已填写发布日期、尚未完成的发布内容笔记行动，涵盖其他入口发起的行动。支持自定义发布时间和跟随截止时间；日期但无具体时刻的行动列入待补时间。完成、取消、终止行动排除。有来源策划的行动按 noteId 去重，优先展示行动当前排期，点击进入已有行动详情，时间调整沿用行动编辑。源内容数据不被投影改写。回归测试 32 项通过。
