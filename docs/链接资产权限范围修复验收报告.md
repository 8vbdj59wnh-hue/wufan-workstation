# 链接资产权限范围修复验收报告

## 修复结论

已将“链接资产”和“我的链接”的读取入口明确分离，并修复平台导入完成后链接资产仍使用旧页面缓存的问题。

## 修改内容

1. 新增独立只读接口 `GET /api/connection-assets`，专用于链接资产页面。
2. 管理员读取链接资产时返回全部连接，包括未分配负责人的新导入连接。
3. 普通运营继续按 `connection_profiles.ownerId = 当前用户ID` 限制可见范围。
4. “我的链接”继续使用原工作台接口：管理员查看全部，普通运营仅查看本人负责链接。
5. 进入“链接资产”时重新读取资产数据，不再仅依赖页面首次加载结果。
6. 平台链接经营导入确认完成后立即刷新链接资产数据。
7. 登录用户变化时清空上一账号的连接页面缓存并按新用户权限重新读取，避免跨账号复用旧范围。

## 验证结果

- 管理员链接资产：返回全部连接，通过。
- 管理员我的链接：返回全部连接，通过。
- 普通运营链接资产：仅返回本人负责连接，通过。
- 普通运营我的链接：仅返回本人负责连接，通过。
- 未分配负责人连接：管理员资产范围可见，普通运营不可见，通过。
- 链接详情与链接医院：继续沿用原负责人服务端校验，未修改。
- 导入逻辑、链接身份、负责人数据、权限模型：均未修改。
- `npm run check`：通过。
