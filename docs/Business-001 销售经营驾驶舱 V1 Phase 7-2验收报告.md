# Business-001 销售经营驾驶舱 V1 Phase 7-2 验收报告

## 1. 实现范围

在现有经营驾驶舱顶部接入标准模块 `sales_business_dashboard`，提供近7日/近30日切换、销售额、利润、利润率、数据覆盖率、每日销售/利润趋势、产品销售排行、链接销售排行及数据健康摘要。旧经营快照区域保留，未改变原业务能力。

## 2. 数据调用与边界

页面组合层只调用：

- `QueryDailySalesSummary`：公司汇总以及产品/链接批量排行；
- `QueryDailySalesTrend`：公司每日趋势；
- `QuerySalesDailyDataQuality`：覆盖率、异常与治理状态。

日报事实表只在既有日报查询 Capability 内读取。页面、UI Module 和驾驶舱组合服务均不直接读取 `connection_sku_sales_daily_facts`，也未创建新的销售计算口径。

## 3. 查询能力补充

`QueryDailySalesSummary` 增加公司维度和批量排行模式。产品排行在查询层通过有效 `product_erp_mappings` 聚合，链接排行在查询层按 `salesLinkId` 聚合。两个排行均单次分组查询、最多返回10项，不逐产品或逐链接请求。

## 4. 隔离验证结果

验证数据库从生产结构副本隔离复制并准备3668条已确认日报事实。

- 近7日：销售额 120,846.14，利润 59,058.6917，趋势7日；
- 近30日：销售额 508,945.9575，利润 238,035.5726，趋势30日；
- 产品排行10项、链接排行10项，均按销售额降序；
- 汇总金额与逐日趋势合计一致；
- 重复查询结果完全一致；
- 当前数据健康为 `error`，异常行8059，按质量 Capability 原样展示；
- 验证样本周期内无缺失日期；组件仍保留 `noData`，不对缺失日期补0。

## 5. 性能与N+1

一次驾驶舱读取固定调用一次质量查询、一次公司汇总、一次趋势、一次产品排行和一次链接排行。排行由服务端聚合、排序、限制条数，页面只渲染结果，不存在逐行或逐对象查询。
